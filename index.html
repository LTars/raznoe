Мои маленькие приложения для телефона.

Пульт Claude Сессии Claude Code: «Продолжить», тишина, запуск. Работает откуда угодно.

Ключ подключения приходит в пуше (кнопка «Пульт») и запоминается на телефоне – один раз открыл из пуша, дальше открывается отсюда.

Кухня Гайд по готовке с таймерами и мостом к Claude. Сейчас – равиоли какао-желток.

Через Tailscale (включи его на телефоне): работает и вне дома, экран не гаснет. Первый раз – по ссылке с токеном из окна сервера, дальше без него. Без Tailscale – домашняя ссылка по Wi-Fi.
