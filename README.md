# Разное

Хаб маленьких приложений на GitHub Pages: https://ltars.github.io/raznoe/

| Папка | Что | Как работает |
|---|---|---|
| [pult](pult/) | Пульт Claude: кнопки сессий, тишина, запуск | Говорит с компом через ntfy; ключ – в ссылке после `#`, хранится на телефоне |
| – | Кухня | Ссылка на страницу, которую раздаёт сам комп (`E:\dev\Kitchen\ravioli\server.ts`), открывается дома по Wi-Fi |

Секретов в репозитории нет: ключи живут только в ссылках и на телефоне.

Почему кухня не здесь целиком: страница с GitHub (https) не может обращаться к компу в домашней сети напрямую, а ретранслятор через ntfy.sh не тянет её трафик (лимит 250 сообщений в день на IP). Для https-кухни, которая открывается и вне дома, подходит Tailscale.
